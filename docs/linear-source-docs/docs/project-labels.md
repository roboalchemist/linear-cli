# Project labels

Organize projects with custom labels relevant to your organization's specific context. Filter projects or issues by their project's label to clearly segment work.

> [!NOTE]
> Workspace-level project labels are available on all plans. Creating team-level project labels requires a [Business](https://linear.app/pricing) or [Enterprise](https://linear.app/pricing) plan.

![Project label picker in a group](https://webassets.linear.app/images/ornj730p/production/bd6d5d4dc03f49d56d4592399c8bf278de0797e1-1402x1178.png?q=95&auto=format&dpr=2)

## Overview

Project labels categorize work at scale and make it easier to filter, group, and locate projects across your workspace. While Initiatives are a great way to group projects by overarching company goal, project labels provide a more flexible and granular grouping dimension.

Use project labels to group project views and filter issues by the labels on their projects. This helps you see work contributing to a common area.

### Create a project label or group

In addition to workspace-level project labels, teams on Business and Enterprise plans can create team-level project labels. A team's project labels are available on projects that include that team.

Manage workspace-level project labels in Settings > Projects > Labels.

Manage team-level project labels from the team's settings. You can also create a project label from the label menu on a project.

As with issue label groups, project label groups are mutually exclusive; only one sub-label per group may be applied to a project.

### Using labels across teams

When a project includes multiple teams, labels from each contributing team or its parent teams can be applied alongside workspace-level labels. If contributing teams have ungrouped labels with the same name, Linear presents them as one label in the picker and on the project.

Labels in different groups, including child labels with the same name, remain separate labels.

### Removing teams from projects

Removing a team from a project also removes that team's project labels from the project. A matching label from another contributing team remains applied when available.

### Privacy

Team-level project labels follow team visibility. Labels from private teams are only visible to people who can access those teams.

### Filtering and grouping

Filtering projects by their label or label group allows you to organize work in units that make sense for your business and the way your work gets done. 

Group projects by label or label group in project views, or issues by their project's label in issue views.

### List project label columns

In a project list view, open **Display** and select a label group to show it as a column.

### Insights

In Insights for an issue view, use project labels to break down issue count, issue age, or triage time by the labels on each issue's project.

Use this functionality to identify which upstream projects are driving the most work across your teams and compare performance metrics between project labels.
